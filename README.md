## 🚀 Featured Projects

### 1. AWS-Based Manufacturing Defect Detection Using Computer Vision
**Python · PyTorch · AWS SageMaker · OpenCV · Streamlit**

- Built a ResNet18-based computer vision model to classify four manufacturing defect categories using the MVTec AD bottle dataset.
- Achieved **97.73% test accuracy**.
- Trained and evaluated the model using AWS SageMaker and Amazon S3.
- Developed a Streamlit application featuring predictions, confidence scores, and Grad-CAM visualizations.

### 2. HouseValue AI — House Price Prediction
**Python · Scikit-learn · Pandas · Streamlit · React**

- Developed an ML application to predict residential property prices.
- Created a preprocessing and feature engineering pipeline for **1,000+ property records**.
- Trained and compared regression models to select a suitable prediction model.
- Built an interactive Streamlit interface for real-time predictions.

### 3. DisasterAid — Disaster Management & Emergency Response
**React.js · JavaScript · Firebase · Firestore · Leaflet.js · Tailwind CSS**

- Developed a web-based platform for disaster reporting and emergency response coordination.
- Integrated Firebase Authentication and Cloud Firestore.
- Implemented interactive maps to visualize incidents and emergency resources.
- Built a responsive interface using React.js, Vite, React Router, and Tailwind CSS.
